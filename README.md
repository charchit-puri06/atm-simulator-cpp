# atm-simulator-cpp
A simple ATM simulation system built using C++ and Object-Oriented Programming concepts. It allows users to check balance, deposit money, withdraw money, and change PIN through a menu-driven interface. 

## Features
- Check account balance
- Deposit money
- Withdraw money
- Change PIN
- Menu-driven interface

## Concepts Used
- Classes and Objects
- Functions
- Loops
- Conditional Statements
- Switch Case
